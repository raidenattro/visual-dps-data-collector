# 2026-08-02 本地启动与复核交互优化

## Windows 本地启动

- 新增 `start-local.bat`，双击后自动进入仓库目录并使用项目 `.venv`。
- 默认监听 `http://127.0.0.1:8767`，约 3 秒后自动打开浏览器。
- 启动前检查 `.venv`、FastAPI、Uvicorn 和端口占用；已有服务时直接打开页面。
- 服务窗口按 `Ctrl+C` 后输入 `Y` 可停止。

## 同帧多人货框配对

- schema v2 原本已支持一帧多个 `bindings`，本次补齐前端编辑能力。
- 人物 A、B 卡片现在分别显示自己的货框清单：
  - 选择人物 A 后点击货框，只修改 A 的绑定；
  - 切换人物 B 后点击另一货框，A 的草稿不会被覆盖；
  - 按 `Y` 后一次写入同一帧的多个 `bindings`。
- 画面货框高亮使用所有人物绑定的并集；右侧摘要同时显示“人物 → 货框”映射。
- 配对颜色按稳定人物身份固定：人物 A 为紫色、人物 B 为橙色；切换编辑人物后，已绑定的人物标签和货框继续保留各自颜色。
- 增加“切换人物”按钮，单按 `Alt` 可在人物 A/B 间循环切换。
- 旧版单人物、扁平 `person_id + confirmed_box_tokens` 数据继续兼容。

## 区间标真可见性

- 区间标真从右侧滚动区域底部提升到“复核完成”按钮下方，默认展开并保持首屏可见。
- 新增快捷键：
  - `A`：当前帧设为首帧；
  - `D`：当前帧设为尾帧；
  - `R`：执行区间标真；
  - `Shift+R`：清除区间。
- 按钮旁直接显示快捷键，降低记忆成本。

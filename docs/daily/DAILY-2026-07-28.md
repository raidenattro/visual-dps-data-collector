# 工作日报（2026-07-28）

## 一、问题背景

| 项 | 内容 |
|----|------|
| 模块 | 回放 Tab — 事件复核标注 |
| 现象 | 标注货框时人体骨架连线/关键点常遮挡画面，干扰点选与核对 |
| 诉求 | 提供可开关的骨架显示；**默认关闭**，需要看姿态时再打开 |
| 环境 | Web SPA；叠加层为 `#playback-canvas` |

## 二、实现内容

### 2.1 回放传输栏「骨架」开关

| 改动 | 说明 |
|------|------|
| UI | `#playback-show-skeleton` checkbox，置于「检测框」左侧 |
| 默认 | 未勾选；`showSkeleton = false` |
| 持久化 | `localStorage` key `datacollect_playback_show_skeleton`（`"1"`/`"0"`） |
| 切换后 | `redrawCurrentFrame()` 立即重绘当前帧 |

### 2.2 绘制守卫

| 改动 | 说明 |
|------|------|
| `drawSkeletonConnections` | `!showSkeleton` 时直接 return |
| `drawSkeletonKeypoints` | 同上（仅 full 模式会调用） |
| 其他层 | 货框、检测框、特征 ID、person_id 标签仍按原逻辑/各自开关，不受影响 |

## 四、验证步骤

| 项 | 操作 |
|----|------|
| 默认关闭 | 打开回放，确认骨架不显示，标注时无遮挡 |
| 打开骨架 | 勾选「骨架」，确认连线（播放）与关键点（暂停）出现 |
| 关闭骨架 | 取消勾选后立即消失，货框等仍正常 |
| 持久化 | 勾选后刷新页面，开关状态保持 |

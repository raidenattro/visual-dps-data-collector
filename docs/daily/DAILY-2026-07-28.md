# 工作日报（2026-07-28）

## 一、问题背景

| 项 | 内容 |
|----|------|
| 模块 | 回放 Tab — 事件复核标注 |
| 现象① | 标注货框时人体骨架连线/关键点常遮挡画面，干扰点选与核对 |
| 现象② | 骨骼特征侧栏默认展开占位，标注时不需要也干扰操作 |
| 现象③ | 已「复核完成」的记录，画面误点货框（未按 Y 标真）后状态变回「复核中」 |
| 环境 | Web SPA + FastAPI；`event_review.json` 存于 `localdata/review/...` |

## 二、实现内容

### 2.1 回放「骨架」显示开关（默认关闭）

| 改动 | 说明 |
|------|------|
| UI | `#playback-show-skeleton`，置于「检测框」左侧 |
| 默认 | `showSkeleton = false`；`localStorage` key `datacollect_playback_show_skeleton` |
| 绘制 | `drawSkeletonConnections` / `drawSkeletonKeypoints` 增加守卫 |

### 2.2 回放「骨骼特征」面板开关（默认关闭）

| 改动 | 说明 |
|------|------|
| UI | `#playback-show-skeleton-features`，置于「特征ID」左侧 |
| 默认 | `showSkeletonFeatures = false`；key `datacollect_playback_show_skeleton_features` |
| 可见性 | `syncSkeletonFeaturesPanelVisibility`：仅开关开启且已加载记录时显示侧栏 |
| 拉数 | 侧栏或「特征ID」任一开启才 `updatePlaybackSkeletonFeaturesUi` |

### 2.3 已复核完成状态不被货框误点降级

| 改动 | 说明 |
|------|------|
| 根因 | 已标真事件上点货框会 `PATCH set_confirmed_box`；后端曾一律 `status=in_progress` |
| 修复 | `set_confirmed_box` 传 `status=None`，由 `save_event_review` 保留 `completed` |
| 仍降级 | 增删标真（toggle / set_all 等）仍回到「复核中」（预期） |

## 四、验证步骤

| 项 | 操作 |
|----|------|
| 骨架默认关 | 打开回放，骨架不显示；勾选后出现连线/关键点 |
| 骨骼特征默认关 | 打开记录后侧栏不展开；勾选后暂停可见特征参数 |
| 特征ID独立 | 仅开「特征ID」时侧栏仍隐藏，但可拉数画标签 |
| 完成态保留 | 已复核完成记录上误点已标真事件货框，列表仍显示「已复核」 |
| 标真仍降级 | 在已完成记录上取消某条标真，应变回「复核中」 |

# 工作日报（2026-07-27）

## 一、问题背景

| 项 | 内容 |
|----|------|
| 模块 | 回放 Tab — 事件复核（播放同步 / 标真货框高亮） |
| 现象 | ① 播放时右侧事件序列与帧号不随进度更新；② 进度条与事件 marker 不同步、异常跳动；③ 暂停后点击标注画面莫名跳转；④ 标真后相邻帧/事件同位置出现紫色涂色且点击无法消除 |
| 样例记录 | `1-1-1-_2/00000000907002400_seg04_4-40_to_5-09__0__full`、`seg07_11-23_to_12-47__0__full` |
| 环境 | Web SPA；`verified_true` / `confirmed_box_tokens` 存于 `localdata/review/{机位}/{clip_key}/event_review.json` |

## 二、实现内容

### 2.1 播放时同步事件序列与帧号

| 改动 | 说明 |
|------|------|
| `duringPlayback` 模式 | 播放循环按帧调用 `syncActiveEventFromPlaybackPosition`，不再仅在 pause/seek 时同步 |
| 解除钉住锁死 | `play` / 开始播放时清除 `playbackEventLinkExact`，避免精确匹配后阻断后续同步 |
| 轻量 UI 刷新 | `patchEventReviewTableActiveState`、`updatePlaybackReviewFrameMeta`、`updatePlaybackReviewPositionUi` |

### 2.2 进度条 timeline 统一与暂停标注跳帧

| 改动 | 说明 |
|------|------|
| `playbackTimelineSecFromVideo` | 连续播放、逐帧 seek、暂停共用 timeline 轴（含 PTS 偏移处理） |
| `updatePlaybackSeekBarUi` | 进度条/时间标签与事件 marker 同轴，消除播放与 seek 间跳动 |
| `redrawCurrentFrame` | 暂停标注/UI 刷新保持当前画面帧，不因钉住事件跳回事件帧 |

### 2.3 标真货框紫色高亮与点击 toggle

| 改动 | 说明 |
|------|------|
| 按帧高亮 | 复核紫色涂色仅落在**当前帧已标真事件**，不再用 `buildVerifiedGroundTruthSegments` 连续段范围扩展 |
| `resolveEventForBoxAnnotation` | 点击货框时定位当前帧含该 token 的事件（优先已标真） |
| 已标真立即落盘 | `toggleConfirmedBoxForEvent` 对已标真条目调用 `persistEventReviewConfirmedBoxes` |

## 四、验证步骤

| 项 | 操作 |
|----|------|
| 播放同步 | 播放视频，观察右侧「第 N 条」与「帧 N / 总数」随进度变化 |
| 进度条 | 播放/拖动/逐帧 seek 后，进度条与事件 marker 位置一致、无 PTS 跳动 |
| 暂停标注 | 暂停后点击货框标注，画面不应跳回其他事件帧 |
| 紫色高亮 | 标真后仅该事件帧显示紫色；点击同一货框可 toggle 并保存（已标真） |
| 相邻帧 | 逐帧步进经过未标真帧，不应残留上一条事件的紫色涂色 |

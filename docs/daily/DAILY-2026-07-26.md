### 2.5 骨架批采集多线程（wip）

| 项 | 说明 |
|----|------|
| 背景 | `batch_skeleton_collect.py` 原单线程逐视频串行，多机组文件夹采集耗时长 |
| 方案 | `--workers` / `-j`（默认 3）；`ThreadPoolExecutor` 按机组文件夹调度，某文件夹完成后自动接下一个 |
| 优化 | 每线程 thread-local 复用 `RTMPosePipeline`；`run_collect_job` 支持传入已有 pipeline |
| 注意 | GPU 下多线程各占一份模型显存，显存不足时减小 `--workers` 或 `--device cpu` |
